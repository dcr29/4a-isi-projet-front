# Pol-eat-heck — Front-end (`4a-isi-projet-front`)

Interface web (HTML / CSS / JavaScript, sans framework) de **Pol-eat-heck**, l'application de réservation de menus et de produits.

# Équipe & dépôts liés

- **Collaborateurs :** `@dcr29` (Front-end), `@Natkbz` (Back-end), `@Tolram89` (Base de données)
- **Back-end (FastAPI) :** [4a-isi-projet-back](https://github.com/Natkbz/4a-isi-projet-back)
- **Base de données (SQLite / SQLModel) :** [4a-isi-projet-db](https://github.com/Tolram89/4a-isi-projet-db)

## Fonctionnement

- Les pages communiquent avec l'API du back via `fetch` (voir `js/api.js`).
- Le front est servi statiquement par FastAPI.
- Conception : voir [docs/conception.md](docs/conception.md).
